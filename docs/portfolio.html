차별점 · 측정이 가설을 교정한다

화려한 기능이 아니라 판단이다

CRAG·Critic·가드레일 같은 레이어를 다 만들어 본 뒤, 측정해서 값을 못 하는 건 걷어냈다. 아래는 측정이 직관을 뒤집은 세 사례.

CASE 01

리랭커 입력이 진짜 레버였다

청킹 heading만 고쳤을 땐 recall이 안 움직였다. 측정이 진짜 병목(리랭커 입력=임베딩 텍스트 일관성)을 지목 → recall@1 0.58 → 0.83. 동의어 사전 없이 어휘갭(부활)까지 해소.

CASE 02

도메인 임베딩 파인튜닝 가설을 반증

"도메인 용어가 일반보다 검색 약할 것"이라 Phase 1을 계획했다. 세그먼트 측정은 정반대 — 도메인 어휘 recall@1 0.842·MRR 0.921 vs 일반 0.500·0.672. 변별력 있는 약관 용어가 강한 앵커. 파인튜닝 트리거 기각.

CASE 03

확신에 찬 오답을 짓지 않는다

병목 판별식이 generation 쪽을 가리키지만, 저장된 RAGAS가 faithfulness=nan + self-judge라 판정을 "확정"이 아니라 "잠정·BLOCKED"로 둔다. 비편향 judge 재측정 전엔 게이트를 안 연다.

precision-first

없는 걸 안전하다 하지 않는다.

  • 못 뽑으면 NULL → RAG. "확신에 찬 오답"을 0으로. recall이 아니라 precision을 보증한다.
  • 면책 강제첨부. "얼마?"에 지급률만 답하면 소비자 손해 → 지급 제외 사유를 항상 붙인다.
  • 준용 NULL·완결성. 특약 청약철회는 "제19조 준용 소관 — 주계약 미확보로 확인 필요"로 정직하게 남긴다.
  • 3-값 보장판정. 별표3 ICD 코드로 보장/미보장→리다이렉트/판정불가 — 억지 판정 안 함.

정직한 한계

아직 못 잡는 것 · 안 잰 것

  • 의미 반전 — "보장한다" vs "보장하지 아니한다"의 반전은 구조 검증만으론 못 잡는다(NLI 확장 지점).
  • generation-bound 미확정 — 비편향 judge(GPT-4o-mini) RAGAS 재측정 전까지 잠정. 게이트가 스스로 감시.
  • GPU-warm 지연 미수록 — retrieve는 lite/CPU 실측만. full 모드 전환이 공존 작업을 방해해 임의 기동 안 함.
  • 일반 세그먼트 n=6 — 방향 신호로만. 골든 확장·재라벨은 코퍼스 마이닝으로 후속.
